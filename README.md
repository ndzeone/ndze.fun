# Сайт ndze

Личная страничка: Человек-паук на главной, проекты с GitHub с просмотром кода, стримы Twitch, видео YouTube, оценка работ от зрителей и задания на стрим (Minecraft, CS2, GTA 5 RP · NovaRP).

## Запуск

Двойной клик по **`start.bat`**: он запускает локальный сервер и открывает http://localhost:8000.
Просто открыть `index.html` двойным кликом не получится — современные модули JS работают только через сервер.

## Что где менять

| Что | Где |
|---|---|
| Ник, описание, ссылки Twitch / YouTube / GitHub, расписание | `assets/js/config.js` |
| Онлайн-база для аккаунтов, работ и заданий | `assets/js/config.js` → `supabase` (инструкция — **SUPABASE.md**) |
| Список репозиториев (включая закрытые) | запусти `tools/sync-github.bat` и вставь токен GitHub |

## Режимы данных

- **Демо (сейчас):** аккаунты, работы и задания хранятся только в твоём браузере. Первый зарегистрированный аккаунт становится админом. Удобно посмотреть, как всё работает.
- **Онлайн (Supabase):** настоящие аккаунты для зрителей. Админ — тот, кто зарегистрировался с почтой из `supabase/schema.sql` (там уже стоит твоя). Настройка ~10 минут по **SUPABASE.md**.

## Репозитории GitHub

- Открытые репозитории видны всем, их код можно листать прямо на сайте (`repo.html`).
- Закрытые показываются только названием и описанием — код недоступен. Чтобы они появились, запусти `tools/sync-github.bat` с токеном (нужно только право **Metadata: Read-only**). Токен никуда не сохраняется — на сайт попадает только файл `data/repos.json`.

## Публикация в интернете

Сайт выкладывается на хостинг Timeweb (**ndze.fun**) автоматически: GitHub Actions (`.github/workflows/deploy.yml`) при каждом push в `main`, раз в сутки и по кнопке Run workflow копирует файлы по SSH (rsync) в `~/ndze/public_html/`. Что не выкладывается — в `.deployignore`.
1. В GitHub → Settings → Secrets and variables → Actions добавь секрет `TIMEWEB_PASSWORD` (пароль от хостинга; **никогда** не пиши его в файлы репозитория) и, по желанию, `REPOS_TOKEN` (токен Metadata: Read-only — тогда список репозиториев обновляется сам).
2. У регистратора домена укажи DNS-серверы Timeweb (ns1.timeweb.ru … ns4.timeweb.org), в панели Timeweb выпусти SSL и раскомментируй HTTPS-редирект в `.htaccess`.
3. В Supabase → Authentication → URL Configuration укажи адрес сайта.
4. Плеер Twitch подхватит домен сам.

Устройство кода для разработчиков — **ARCHITECTURE.md**.
